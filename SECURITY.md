# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.6.x   | ✅        |

## Reporting a Vulnerability

If you discover a security vulnerability in this SDK, please report it
responsibly:

1. **Do not open a public GitHub issue** for security vulnerabilities.
2. Use GitHub's private vulnerability reporting:
   **Security → Report a vulnerability** at
   [Open a private report](https://github.com/afurm/typesafe-sdk-ruby/security/advisories/new).
3. Include a description of the issue, steps to reproduce, and the affected
   version(s).

You can expect an initial response within 7 days. Please allow up to 90 days
for a fix to be released before public disclosure.

## Scope

This SDK is an unofficial community port. Vulnerabilities in the TypeSafe AI
API itself should be reported to TypeSafe AI directly.
